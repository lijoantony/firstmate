Why R4 matters - the ls-remote pattern must be the FULL ref.
Same repo, same remote, the only difference is the pattern:

$ git ls-remote --exit-code --heads origin rel/2026.9      # bare name
   2e00f5814b68b3f3004fb1ef93157aeab03e5ef8	refs/heads/mirror/rel/2026.9
   exit 0  -> a remote mirror/ branch is read as 'the base is on origin'

$ git ls-remote --exit-code --heads origin refs/heads/rel/2026.9   # what the product asks
   exit 2  -> the remote is reachable and has no such branch
